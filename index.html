PERSONAL ARCHIVE

私人 PDF 備份，
方便日後查找。

ZSXQ PDF Archive 是僅供擁有者本人使用的歸檔工具：自動將指定 PDF 備份至自己的 Google Drive，並建立 Markdown 與原始 PDF 的連結對照。

01 / 備份

將指定檔案存入 Drive

工具在擁有者的電腦上執行，透過 rclone 與 Google Drive API 上傳 PDF，依日期保存。

02 / 核對

確認備份完整

完成上傳後核對檔案數量、大小及內容，讀取檔案中繼資料與 Google 回傳的瀏覽連結。

03 / 查找

保留私人連結索引

連結索引保存在本機，並可同步至擁有者控制的私人 GitHub 倉庫。連結仍受原有 Drive 權限限制。

這個網站只提供工具說明

網站不提供上傳、登入或報告查閱功能。工具不會自動將 Drive 檔案設為公開；本站不包含 PDF、私人檔案連結或 OAuth 憑證。
