# ZSXQ PDF Archive information site

Buildless public information pages for a personal Google Drive PDF archive.

Only these static pages and their shared stylesheet belong in this repository.
Never add reports, private link manifests, runtime configuration, OAuth credentials,
logs, or data copied from the archive.

## Deployment

Publish the `main` branch root with GitHub Pages. No packages or build step are required.

After publishing, verify the actual live URLs before using them in Google Auth Platform Branding:

- Home: `https://cycjason214.github.io/zsxq-pdf-archive-info/`
- Privacy: `https://cycjason214.github.io/zsxq-pdf-archive-info/privacy.html`
- Terms: `https://cycjason214.github.io/zsxq-pdf-archive-info/terms.html`
- Authorized domain: `cycjason214.github.io`

These are the intended deployment URLs, not evidence that deployment has succeeded.

The private report repository and Google Drive file sharing settings are independent of this site.
